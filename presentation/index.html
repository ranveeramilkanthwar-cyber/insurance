🖥️ GPU Training

AI Model Training with GPU

⚡ XGBoost GPU Architecture
  • Algorithm: Gradient Boosting (ensemble of weak learners)
  • GPU Flag: device='cuda' — uses NVIDIA CUDA cores
  • Tree method: tree_method='hist' — GPU histogram
  • Estimators: 500 trees, max_depth=8
  • Regularization: reg_alpha=0.1, reg_lambda=1.0
  • Subsampling: 85% row + 85% column per tree
  • CPU Fallback: Automatic if no GPU detected
from xgboost import XGBRegressor

model = XGBRegressor(
  n_estimators=500,
  tree_method="hist",
  device="cuda", # GPU 🚀
  max_depth=8,
  learning_rate=0.05,
  subsample=0.85,
)

GitHub Deployment Guide

📦 Upload to GitHub
git init
git add .
git commit -m "feat: InsureAI v1.0"
git remote add origin <your-repo-url>
git push -u origin main
☁️ Frontend — Vercel
  • Import GitHub repo → Vercel dashboard
  • Set Root Directory: frontend/
  • Auto-deploy on every git push
  • Update API URL: Vercel env var NEXT_PUBLIC_API_URL
🐳 Backend — Render / Railway
  • Connect GitHub repo to Render.com
  • Set Root Directory: backend/
  • Build command: pip install -r requirements.txt && python generate_dataset.py && python train.py
  • Start command: uvicorn main:app --host 0.0.0.0 --port 10000
